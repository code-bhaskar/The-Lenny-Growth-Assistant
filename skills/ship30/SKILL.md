# Ship 30 for 30 Essay Skill

Purpose: transform grounded transcript insights into a long-form digital-writing style essay.

Requirements:
- Approximately 1,250 words.
- Start with a strong hook.
- Follow one clear narrative arc.
- Use short paragraphs.
- Use headings, bullets, and selective bold emphasis.
- End with one practical takeaway.
- Keep claims grounded in the provided transcript evidence.
