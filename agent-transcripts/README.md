# Agent transcripts and logs

This folder contains development evidence for the Lenny Growth Assistant build.

## Export method
- Arena conversation excerpts were exported manually into markdown.
- Terminal/test logs were copied from actual command output.

## Files
- `session-01.md` — manually exported agent-session transcript excerpts
- `failing-test-output.txt` — verbatim failing pytest output excerpt from an actual run
- `fix-log.md` — diagnosis and correction trail
- `redactions.md` — what was removed or generalized
- `2026-09-15-arena-session.md` — condensed summary retained for quick review
